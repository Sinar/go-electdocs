# PHASE 0 REVIEW: Compare to-review.csv against 2016 DUN Sarawak Results

## Overview

This review compares **ORDINARY VOTE** rows in `to-review.csv` (PRU-15, 2022 parliamentary election)
against the 2016 Sarawak DUN election files in `data/sarawak-dun-2016/OUTPUT/Sarawak-N.XX.csv`.

**Comparison scope:** Structural fields only (PAR code/name, DUN code/name, polling district code/name, polling centre).
- Postal vote rows are excluded (different aggregation level: PAR-level in 2022 vs DUN-level in 2016).
- Early vote rows are excluded (polling centres commonly change between elections).
- Summary/totals rows in 2016 files (empty polling district code) are excluded.
- Matching is done at the **DUN level** and **Polling District level** (not row-level), because
  2016 files have duplicate (PD code, channel) combinations across multiple polling centres within
  the same PD, while 2022 uses sequential channel numbers.

## Conclusion

### Key Findings

1. **DUN Coverage:** All 80 DUNs from 2016 are present in 2022. Two additional DUNs (N.79 BUKIT KOTA, N.82 BUKIT SARI) are in 2022 but were not contested in 2016.

2. **PAR Code Discrepancies (28 DUNs):** The 2016 DUN files have PAR codes that do NOT match their own polling district code prefixes. For example, N.11's polling districts start with `195/11/...` (indicating P.195) but the 2016 file says `P.192`. The 2022 data correctly uses `P.195`. This is a data quality issue in the **2016 source files**, not in `to-review.csv`.

3. **PAR Name Changes (28 DUNs):** Follow from the PAR code changes. Where PAR codes differ, the PAR names naturally differ too.

4. **DUN Name:** Only 1 difference found — an apostrophe vs backtick variation, which is a minor encoding difference.

5. **Polling District Coverage:** 854 PDs matched between 2016 and 2022. 0 PDs are only in 2016 (removed/merged), 1 only in 2022 (new/split).

6. **Polling Centre Names:** Most differences are abbreviation expansions (e.g. "SEK. KEB." → "SEKOLAH KEBANGSAAN"). Some centres were genuinely renamed or replaced between elections.

7. **Row Counts:** Every DUN shows more ordinary vote rows in 2022 than 2016, consistent with voter population growth requiring more voting channels.

### Overall Assessment

The structural data in `to-review.csv` is **consistent and reasonable** when compared against the 2016 baseline:
- DUN codes and names match (with one trivial apostrophe variant).
- Polling district codes and names are stable across elections.
- The PAR code differences are a known issue in the 2016 source data, not in the 2022 file.
- Growth in channels/rows is expected between elections.
- No anomalous structural issues were found in `to-review.csv`.
